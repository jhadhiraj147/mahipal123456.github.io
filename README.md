# Text to Handwriting Web Application

## Introduction
Welcome to the modernized **Text to Handwriting Web Application**! This tool allows users to convert typed text into a realistic handwritten format, making digital text look exactly like it was written by hand. It is perfect for creating personalized notes, assignments, university lab records, artistic projects, and more.

## About Me & This Project
**Simplified and actively enhanced by Mahipal Kumawat (@jhadhiraj147)**. 

This project was originally forked from the popular open-source Text-to-Handwriting repository. I have completely overhauled, simplified, and enhanced it to function as a premium, distraction-free **True WYSIWYG (What You See Is What You Get)** editor.

## Upgraded Features
We completely revamped the engine to feel like a high-end word processor rather than a simple conversion script:
- **True WYSIWYG Pagination**: Type seamlessly and watch your text automatically and instantly cascade down into physically accurate, multi-page paper boundaries.
- **Pure Document Exporting**: Generate perfectly scaled, multi-page **.pdf** documents with a single click, completely removing the hassle of managing individual PNG images.
- **Dynamic Workspace Zoom**: Scale the physical paper dynamically to fit perfectly on any monitor size without altering your actual A4/letter document export resolution.
- **Instant MathJax Rendering**: Support for inline (`$x^2$`) and block (`$$x^2$$`) LaTeX! Click *"Render All"* to instantly convert your entire document's LaTeX blocks into handwritten math equations!
- **Premium Distraction-Free UI**: Stripped down the loud, messy marketing elements to provide a sleek, dark-mode focused workspace dedicated purely to the tool.

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation
No installation is required. Simply visit the application URL above to start using the tool directly in your browser.

### Usage
1. **Explore the Workspace**: You are automatically greeted with a clean, physical A4 paper canvas.
2. **Enter Text**: Type continuously or paste your text. The engine automatically handles creating new pages and flowing your text across them.
3. **Select Style**: Choose from a variety of handwriting styles, ink colors, and paper templates in the Left Sidebar.
4. **Customize**: Adjust the Workspace Zoom so the paper comfortably fits your specific monitor height.
5. **Download**: Use the sleek control dock strictly seated below the paper to export your creation cleanly into a multi-page PDF document.

## Technologies Used
- **HTML5 & CSS3**: Structure and premium styling.
- **Vanilla JavaScript**: High-performance Interactivity, Pagination engine, and DOM logic.
- **Quill.js**: Rich text framework used to construct the WYSIWYG editor.
- **jsPDF & html2canvas**: High-definition PDF generation.
- **MathJax / KaTeX**: Displaying and rendering mathematical equations.
